# Fault Codes and First Response

## Filling line FL-100

- E101 Fill weight out of tolerance: stop, verify load cell calibration, check nozzle wear; do not adjust set points beyond the recipe limits.
- E117 Door interlock open: confirm all guards closed; never bypass the interlock.
- E140 Servo overtemperature: allow cooling, check the cabinet filter; a second E140 within one shift becomes a P2 work order.

## Conveyor CV-200

- C205 Belt tracking fault: stop, inspect tracking rollers, re-tension per the tension table.
- C220 Motor overload: check for jammed product; if the overload repeats, raise a P2 work order.

## Pasteuriser PA-300

- T301 Holding-tube temperature below set point: product since the last in-spec reading goes on quality hold; raise a P1 work order.
- T315 Flow diversion valve fault: P1; do not restart production until the valve test passes.

## Escalation

Any fault code affecting food safety (T301, T315, E101 with contamination risk) is escalated to the quality supervisor immediately.
