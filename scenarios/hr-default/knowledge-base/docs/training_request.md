# 培训申请政策


## 概述

公司鼓励员工持续学习和职业发展。本政策规定了培训申请的流程和预算管理。

## 培训类型

- 内部培训：公司组织的技能培训、讲座
- 外部培训：第三方机构课程、认证考试
- 在线学习：线上课程平台（如Coursera、Udemy）
- 会议/研讨会：行业会议参加

## 申请流程

1. 确定培训主题和目标
2. 填写培训申请表（包含：主题、参加人数、时长、预算、期望成果）
3. 说明当前技能水平和培训必要性
4. 注明是否需要特殊设施或住宿
5. 提交主管审批
6. 预算超过5000元需部门经理审批

## 预算标准

- 每人每年培训预算：5000-15000元
- 团队培训：按人数×标准计算
- 认证考试费用：公司承担首次费用
- 差旅费用：按公司差旅标准报销

## 培训后要求

- 提交培训总结报告
- 与团队分享学习成果
- 将所学应用于工作中
- 获得的证书提交HR备案
