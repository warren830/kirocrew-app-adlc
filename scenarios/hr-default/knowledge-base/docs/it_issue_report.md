# IT问题报告与支持政策


## 概述

本政策规定了员工报告IT问题和获取技术支持的流程。

## 常见问题类型

- 账户问题：登录失败、密码重置、权限错误（如403/401错误）
- 网络问题：无法连接、速度慢、VPN故障
- 软件问题：应用崩溃、功能异常、兼容性问题
- 硬件问题：设备故障、外设不工作
- 安全问题：可疑邮件、病毒警告、数据泄露

## 报告流程

1. 尝试基本排查（重启、清除缓存、检查网络）
2. 如问题持续，提交IT工单
3. 工单内容：问题描述、错误信息、发生时间、影响范围、是否为反复出现的问题
4. 选择优先级：
   - 紧急：影响业务运行
   - 高：影响工作效率
   - 中：有替代方案
   - 低：改进建议

## 响应时间

- 紧急：1小时内响应
- 高优先级：4小时内响应
- 中优先级：1个工作日内响应
- 低优先级：3个工作日内响应

## 自助资源

- 内部Wiki：常见问题解答
- 知识库：操作指南和教程
- IT公告板：已知问题和维护通知
