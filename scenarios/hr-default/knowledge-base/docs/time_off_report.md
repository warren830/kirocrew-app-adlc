# 休假管理政策


## 概述

本政策规定了员工申请各类休假的流程和要求。适用于所有正式员工。

## 休假类型

公司提供以下休假类型：
- 年假（带薪）：每年15-20天，根据工龄递增
- 病假（带薪）：每年10天
- 事假（无薪）：需提前申请
- 婚假：3-15天（根据当地法规）
- 产假/陪产假：按国家规定执行
- 丧假：1-3天

## 申请流程

1. 登录HR系统提交休假申请
2. 填写休假类型、起止日期、天数
3. 说明休假原因（可选）
4. 提供紧急联系方式
5. 等待直属主管审批
6. 审批通过后系统自动通知

## 提前通知要求

- 年假：至少提前5个工作日申请
- 病假：当天或次日补交申请，需提供医疗证明
- 事假：至少提前3个工作日
- 长假（超过5天）：至少提前2周申请

## 审批规则

- 3天以内：直属主管审批
- 3-5天：部门经理审批
- 5天以上：需HR部门复核
- 节假日前后的休假需提前1个月申请

## 休假期间要求

- 设置邮件自动回复
- 指定工作代理人
- 提供紧急联系方式
- 确保交接工作完成
