# 职场骚扰举报政策


## 概述

公司对任何形式的职场骚扰零容忍。本政策保护每位员工的尊严和安全。

## 骚扰类型

- 言语骚扰：侮辱性言论、不当玩笑、威胁
- 身体骚扰：不当身体接触、跟踪
- 网络骚扰：社交媒体骚扰、恶意邮件、网络欺凌
- 性骚扰：不受欢迎的性暗示、要求
- 歧视性骚扰：基于性别、种族、宗教等的骚扰

## 举报流程

1. 记录骚扰事件（时间、地点、涉及人员、具体行为）
2. 保留证据（截图、邮件、聊天记录）
3. 通过以下渠道举报：
   - HR部门（面谈或邮件）
   - 公司举报热线
   - 直属主管（如主管非涉事方）
   - 匿名举报系统
4. 提供目击者信息（如有）

## 保密与保护

- 举报信息严格保密
- 禁止对举报人进行报复
- 调查过程保护双方隐私
- 举报人可申请工作调整（如换组、远程办公）
- 违反保密规定者将受纪律处分

## 调查处理

- HR在收到举报后3个工作日内启动调查
- 调查周期：通常2-4周
- 调查结果通知双方
- 处理措施：警告、调岗、降职、解雇（视情节严重程度）

## 支持资源

- 员工援助计划（EAP）：免费心理咨询
- 法律咨询：公司提供法律支持
- 调解服务：轻微冲突可申请调解
