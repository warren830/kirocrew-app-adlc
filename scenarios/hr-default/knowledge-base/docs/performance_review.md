# 绩效考核政策


## 概述

本政策规定了员工绩效评估的周期、标准和流程。适用于所有转正后的员工。

## 考核周期

- 年度考核：每年12月-1月
- 半年回顾：每年6月
- 季度检查：每季度末（可选）
- 试用期考核：入职3个月/6个月

## 考核维度

- 工作目标完成度（40%）
- 核心能力表现（30%）
- 团队协作与沟通（20%）
- 创新与改进（10%）

## 评分标准

- 5分：卓越 - 远超预期
- 4分：优秀 - 超出预期
- 3分：良好 - 达到预期
- 2分：需改进 - 部分达标
- 1分：不合格 - 未达标

## 流程

1. 员工完成自评
2. 直属主管评估
3. 一对一绩效面谈
4. 制定改进/发展计划
5. HR审核并归档
6. 结果与薪酬调整挂钩

## 申诉机制

员工对考核结果有异议的，可在收到结果后10个工作日内向HR提出书面申诉。
