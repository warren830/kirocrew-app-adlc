# 员工福利注册政策


## 概述

本政策说明员工福利计划的注册流程和可选方案。所有正式员工入职30天内需完成福利注册。

## 可选福利计划

- Plan A（基础版）：基本医疗保险 + 意外险
- Plan B（标准版）：医疗 + 牙科 + 视力保险
- Plan C（高级版）：全面医疗 + 牙科 + 视力 + 补充商业保险
- 退休金计划：公司匹配最高6%

## 注册流程

1. 确认个人信息已更新
2. 选择福利计划等级
3. 添加受益人信息
4. 选择联系偏好（邮件/电话/社交媒体）
5. 确认并提交
6. HR审核后生效

## 变更窗口

- 新员工：入职30天内
- 年度开放注册：每年11月1日-30日
- 生活事件变更：结婚、生育、离婚等事件后30天内可调整

## 注意事项

- 确保个人信息（地址、联系方式）为最新
- 受益人信息需定期更新
- 计划变更在下月1日生效
