# 员工手册 - 通用政策


## 概述

本手册涵盖公司各项通用人事政策和员工须知。

## 工作时间

- 标准工时：每周40小时
- 弹性工作：核心时间10:00-16:00，其余时间灵活安排
- 加班：需提前申请，按法定标准支付加班费
- 远程办公：经主管批准后可申请

## 考勤管理

- 打卡方式：系统打卡/人脸识别
- 迟到/早退：每月累计3次以上需说明原因
- 旷工：未经批准缺勤视为旷工

## 薪酬福利

- 发薪日：每月15日
- 社保公积金：按国家规定缴纳
- 年终奖：根据公司业绩和个人绩效
- 补充福利：餐补、交通补、通讯补

## 行为规范

- 遵守公司规章制度
- 保护公司机密信息
- 维护良好的工作环境
- 尊重同事，禁止歧视和骚扰

## 离职流程

- 提前30天提交书面辞职申请
- 完成工作交接
- 归还公司财产
- 办理离职手续
- 结算工资和福利
