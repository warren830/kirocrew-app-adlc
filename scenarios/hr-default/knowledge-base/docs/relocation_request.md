# 员工调动/搬迁政策


## 概述

本政策适用于因工作需要或个人原因申请调动或搬迁的员工。

## 搬迁原因

- 工作调动（公司安排）
- 个人原因（家庭、教育等）
- 项目需要（临时派驻）

## 申请流程

1. 提交搬迁申请（说明原因、目的地、期望时间）
2. 说明住房需求（户型、预算）
3. 确认是否需要就业协助
4. 确认家属随迁情况
5. HR评估并安排

## 公司支持

- 搬迁补贴：根据距离和级别，3000-30000元
- 临时住房：最长3个月过渡期住房补贴
- 搬家费用：实报实销（上限10000元）
- 就业协助：协助配偶在新地点找工作（如适用）
- 子女教育：提供当地学校信息

## 时间安排

- 申请审批：5-10个工作日
- 搬迁准备期：1-3个月
- 到岗报到：按约定日期
