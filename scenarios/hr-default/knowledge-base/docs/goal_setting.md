# 目标设定与管理政策


## 概述

本政策指导员工制定年度工作目标和个人发展计划，确保个人目标与公司战略对齐。

## 目标类型

- 业务目标：与岗位职责直接相关的工作成果
- 发展目标：技能提升、职业成长
- 团队目标：协作和领导力相关
- 创新目标：改进流程、提出新方案

## SMART原则

所有目标应符合SMART原则：
- Specific（具体）：明确要达成什么
- Measurable（可衡量）：有量化指标
- Achievable（可实现）：在能力范围内
- Relevant（相关）：与工作和公司目标相关
- Time-bound（有时限）：设定完成期限

## 设定流程

1. 员工草拟目标（3-5个）
2. 与主管讨论并调整
3. 确定所需资源（时间、资金、支持）
4. 设定里程碑和检查点
5. 确定评估频率（周/月/季度）
6. 双方确认并录入系统

## 跟踪与回顾

- 月度自查：员工自行评估进度
- 季度回顾：与主管一对一讨论
- 半年调整：根据业务变化调整目标
- 年终评估：纳入绩效考核

## 资源支持

- 培训预算：用于技能提升目标
- 导师计划：高级员工一对一指导
- 跨部门项目：拓展视野和能力
- 工具和设备：按需申请
