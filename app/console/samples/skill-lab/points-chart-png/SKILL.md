# 会员积分柱状图：points-chart.png

会员的积分数据在当前工作目录的文件里（CSV 或 Excel；有会员号、本期积分两列，可能还有别的列）。要你画图时：

1. 用 Bash 运行 python3 读文件：CSV 用 csv 模块（编码 utf-8-sig），Excel 用 openpyxl。会员号按文本原样保留（00031 不能变成 31）；同一会员出现多次（或在几个文件里）时本期积分相加；“1,200”这样的写法当 1200。别的列不用。
2. 用 matplotlib 画**横向**柱状图（barh）：每位会员一根柱子，柱长是本期积分；按本期积分从高到低排，最高的在最上面。
3. 柱子都用蓝色 #2563EB，本期积分最高的那一位用橙色 #F97316。
4. 每根柱子右端标上它的积分（整数，不加千分位）。
5. 标题「会员本期积分」，横轴标签「本期积分」，纵轴标签是会员号；不要图例。
6. 存为当前工作目录的 `points-chart.png`（figsize=(8, 4.5)，dpi=100）。不要改动、覆盖或另存输入文件。
7. 回复只用一句话：已生成 points-chart.png，共几位会员，最高的是谁、多少分。
