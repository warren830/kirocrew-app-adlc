# 会员积分报表：points-report.xlsx

用户给你会员的积分数据（对话里的表格、CSV、清单或一段话），要你做成报表时：

1. 生成 Excel 文件，文件名固定为 `points-report.xlsx`，放在当前工作目录。用 Bash 运行 python3 和 openpyxl 生成（`python3 - <<'EOF' … EOF`）；不要只在回复里画表格，也不要生成 CSV。
2. 只有一个工作表，名为「积分明细」。
3. 第一行是表头，三列依次为：会员号、本期积分、到期积分。表头加粗，冻结首行。
4. 每位会员一行，按会员号升序排列。会员号原样保存为文本（M0012、00031 这样的写法不变，不能变成数字）；积分写整数（“1,200 分”写 1200）；数据里没有到期积分的写 0。
5. 最后一行是合计：A 列写「合计」，B 列和 C 列用 SUM 公式（例如 =SUM(B2:B4)），不要算好后写死数字。
6. 写完用 openpyxl 重新打开文件，核对工作表名、表头、会员行数和合计行。
7. 回复只用一句话：已生成 points-report.xlsx，共几位会员，本期积分合计多少。
